# EBZ-3DHologramFan-Banco-de-Contenidos
Banco de contenidos audiovisuales tridimensionales generados con inteligencia artificial para el prototipo de visualización holográfica 3D EBZ 3DhologramFan, desarrollado como recurso didáctico en el programa de Tecnología en Desarrollo de Sistemas Informáticos de las Unidades Tecnológicas de Santander.
